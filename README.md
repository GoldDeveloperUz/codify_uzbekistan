# CODIFY — React.js Loyihasi

## Ishga tushirish

```bash
# 1. Papkaga kiring
cd codify-platform

# 2. Dependencies o'rnating
npm install

# 3. Dev server ishga tushiring
npm run dev
```

Brauzerda: http://localhost:5173

## Build (production)

```bash
npm run build
npm run preview
```

## Vercel'ga deploy

1. `npm run build` bajaring
2. `dist/` papkasini Vercel'ga drag-and-drop qiling
   yoki GitHub'ga push qilib Vercel'dan import qiling
